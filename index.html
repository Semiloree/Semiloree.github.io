    Asteroid Shooter Game

    Asteroid Shooter Game is a responsive and interactive game where players control a military jet to destroy falling asteroids. Players enter their name, are welcomed with a personalized message, and start the game by clicking "Play Game." Asteroids descend from the top, and players must click them three times to destroy them. A life bar decreases if asteroids escape, while a points bar tracks destroyed asteroids. Players have 60 seconds to survive and score points. If the life bar depletes, a "Game Over" message with a retry option appears. If victorious, a celebratory "You Win" message and retry button are displayed. The game highlights dynamic mechanics, personalized interaction, and a responsive design.

    Languages or tools used
    HTML CSS JavaScript
